# 數位雨幕

靈感來自《駭客任務》的網頁字元雨：黑色背景上，綠色字元不斷向下流動，搭配明亮前端與漸淡尾跡，適合在 Mac 的 Chrome 中全螢幕播放。

只需一個 `index.html`，不必安裝套件、設定後端或執行建置，也能離線使用。

## 功能

- 綠色字元雨，各列具有不同的速度、長度與明暗。
- 可調整流動速度、字元大小與亮度。
- 自訂出現的中文、日文、英文字母、數字或符號。
- 一鍵還原預設字元。
- 全螢幕播放與暫停／繼續。
- 閒置約 3.5 秒後隱藏控制面板與游標；移動滑鼠即可喚回。
- 可選擇保持螢幕開啟，實際支援程度依瀏覽器與系統而定。
- 隨視窗大小調整畫面，分頁隱藏時停止更新字元雨。

## 本機使用

1. 下載 `index.html`。
2. 用 Chrome 開啟檔案，或將檔案拖入 Chrome 視窗。
3. 點選「進入全螢幕」。
4. 停止操作，待控制面板隱藏即可欣賞雨幕。

本機播放不需要網路連線。若瀏覽器無法透過網頁按鈕進入全螢幕，可使用瀏覽器本身的全螢幕選項。

## 操作方式

| 操作 | 功能 |
| --- | --- |
| `F` | 進入／離開全螢幕 |
| 空白鍵 | 暫停／繼續動畫 |
| 移動滑鼠或點擊畫面 | 顯示控制面板 |
| 流動速度 | 調整為 0.3×～2.5×，預設 1.0× |
| 字元大小 | 調整為 12～34 像素，預設 20 |
| 亮度 | 調整為 20%～100%，預設 70% |
| 出現的字元 → 套用 | 將畫面立即換成自訂字元 |
| 還原預設 | 恢復預設的片假名、數字與符號 |
| 保持螢幕開啟 | 請求瀏覽器在播放期間保持螢幕開啟 |

在輸入欄位或按鈕取得焦點時，快捷鍵不會攔截輸入；控制面板也會保持顯示，方便操作。

### 自訂字元範例

| 輸入內容 | 顯示效果 |
| --- | --- |
| `01` | 只出現 0 與 1 |
| `駭客任務` | 隨機出現「駭」「客」「任」「務」 |
| `ABC123@#$` | 混合英文字母、數字與符號 |
| `ｱｲｳｴｵｶｷｸｹｺ` | 使用半形日文片假名 |

字元會隨機選取，不會按照輸入的句子順序排列。空白會忽略，不能套用全空白內容。重複輸入某個字元會提高它被選中的機率。

目前設定只在本次開啟期間有效，重新整理或重開頁面後會恢復預設。

## 發布到 GitHub Pages

1. 建立 GitHub 儲存庫，將 `index.html` 與 `README.md` 上傳到 `main` 分支的根目錄。
2. 進入儲存庫的 **Settings → Pages**。
3. 在 **Build and deployment → Source** 選擇 **Deploy from a branch**。
4. 選擇 `main` 分支與 `/(root)` 目錄，再按 **Save**。
5. 等待發布完成，使用 Pages 設定頁顯示的網站網址開啟。

一般專案網站網址的形式為 `https://<帳號>.github.io/<儲存庫名稱>/`。後續更新同一發布分支的 `index.html`，GitHub Pages 會重新發布。

操作細節請參考 [GitHub Pages 官方發布來源設定說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 檔案與技術

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 完整網頁，內含樣式、動畫程式與圖示 |
| `README.md` | 專案與操作說明 |

採用 HTML Canvas 2D、CSS 與原生 JavaScript，無第三方套件、外部字型下載或追蹤程式。動畫以 `requestAnimationFrame` 排程，繪製更新率上限約為每秒 30 次，實際流暢度依裝置而定。

字形使用系統可用字型，優先選用 `Hiragino Kaku Gothic ProN`、`Yu Gothic`，再回退至等寬字型；不同裝置可能呈現不同字形。本專案並未使用電影原版專用字型，也沒有將字元左右鏡像。

## 使用提醒

- 這是手動開啟的網頁動畫，不會自動啟動、鎖定電腦或取代 macOS 的系統螢幕保護程式。
- 若系統啟用了「減少動態效果」，頁面會以暫停狀態開啟；按「繼續」即可播放。
- 「保持螢幕開啟」使用 Screen Wake Lock API，可能受瀏覽器支援、安全環境及系統省電設定限制。若本機開啟時無法使用，可改用 GitHub Pages 的 HTTPS 網址；仍不支援時，頁面會顯示提示。
- 「亮度」只調整網頁中字元的明暗，不會更動實體螢幕亮度。
